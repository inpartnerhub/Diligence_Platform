# Diligence Platform — demo

A demo of the Diligence Platform with **fictional data only**. Pick a role (Partner, Project Manager, Analyst,
Client, Target, Observer, Super Admin) and enter the app without a login form.

- Access needs the demo password you received.
- Open the app through its direct address (`https://<owner>-<space>.hf.space`); inside the Hugging Face page the
  browser may block the sign-in cookie.
- Every start creates a fresh demo project, so changes made during a demo disappear when the Space restarts.
  The first start takes several minutes.

Built from branch `demo` of the Diligence Platform repository (`deploy/huggingface`). Not a production deployment.
